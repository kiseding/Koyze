# Koyze

Koyze 是一个用 Flutter 编写的免费音乐查找、播放与收藏管理工具。它把在线搜索、本地音乐、歌单收藏、下载管理、歌词、排行榜、推荐、听歌统计和云端同步放在同一个应用里，目标是尽量少打断地完成「找到歌 → 播放 → 收藏 / 下载 → 管理歌单 → 多端同步」这条完整链路。

> 项目定位是音乐查找与个人音乐库管理助手。请在遵守当地法律法规、平台条款和版权要求的前提下使用。

## 功能概览

### 在线音乐搜索

- 支持多平台搜索：全网、QQ、酷我、网易、本地音乐、收藏列表。
- 内置搜索源管理，默认平台可在设置中切换。
- 搜索结果支持分页加载、滚动加载更多、播放、收藏、加入歌单和下载。
- 搜索时会同时补充本地音乐匹配结果，方便把设备上的歌曲和网络结果放在同一个入口里查找。
- 支持歌单 / 歌曲列表搜索和歌单详情播放。
- 首页提供搜索弹窗入口，带展开动画和移动端输入焦点处理。

### 播放器

- 基于 `audio_service` + `just_audio`，支持后台播放、媒体通知、耳机 / 系统媒体按键控制。
- 支持播放 / 暂停、上一首、下一首、进度拖动、队列管理、循环和随机。
- 支持大歌单惰性分页播放，不需要一次性把所有歌曲都塞进系统媒体队列。
- 迷你播放器常驻底部，全屏播放器从迷你栏展开，并支持跟手下拉关闭。
- 播放队列弹窗支持拖拽跟手、限制最高高度，并针对歌曲列表滚动做了交互处理。
- 支持音频输出路由变化恢复，例如耳机、蓝牙或系统输出设备切换。
- 支持恢复上次播放会话，可选择是否启动 App 后自动继续播放。
- 支持睡眠定时，到点自动暂停播放。
- iOS 支持锁屏同步、当前歌词行同步和小组件深链打开播放器。

### 音质与播放地址解析

- 支持 128k、320k、FLAC、FLAC 24bit、Hi-Res 等音质选项。
- 播放和下载可分别配置音质。
- 播放解析采用「先同源音质回退，再跨平台回退」的策略：优先在当前源里从目标音质向较低音质降级，实在没有可播地址时再尝试其他平台。
- 自定义源优先于内置源，可按启用顺序参与解析。
- 播放链接解析带超时、取消、并发去重和失败冷却，减少切歌、预加载和重复点击导致的状态错乱。
- 本地文件直接使用文件路径播放，不进入网络音源解析链。

### 歌词

- 支持从内置 / 自定义音源获取歌词。
- 支持 LRC、QRC / 逐字歌词解析。
- 支持歌词缓存，优先保留带逐字时间轴的歌词。
- 支持本地文件内嵌歌词。
- 播放器展示当前歌词行和翻译，iOS 锁屏也可同步当前歌词行。

### 歌单与收藏

- 内置系统歌单：我喜欢、最近播放、本地音乐。
- 支持创建、重命名、删除普通歌单。
- 支持从搜索结果、排行榜、推荐、本地音乐和播放器加入歌单。
- 支持歌单内搜索歌曲，并可直接定位到对应歌单详情。
- 歌单详情支持分页浏览、播放全部、从指定歌曲开始播放。
- 普通歌单支持编辑排序。
- 收藏列表支持长按进入多选模式，可批量取消收藏和批量下载。
- 收藏列表多选的「全选」只作用于当前页最多 100 首歌曲，翻页会清空选择，避免误操作整个收藏库。
- 支持重复歌曲检测，可选择删除冗余项或一键清理收藏中的重复歌曲。
- 最近播放会自动维护最近歌曲，限制数量并保持封面等已有信息。

### 下载管理

- 支持把歌曲加入下载任务，下载音质独立配置。
- 支持进行中、已完成、全部三个任务视图。
- 展示整体进度、已完成数量、总下载大小和实时速度。
- 单任务支持暂停、恢复、取消、重试和删除已下载文件。
- 支持暂停全部、清理已完成任务、清理失败任务。
- 支持「仅 Wi‑Fi 下载」，网络变化时自动遵守当前策略。
- 下载完成后会写入下载目录，并自动纳入本地音乐索引和「本地音乐」系统歌单。
- 下载服务会在启动时恢复任务、处理残留 `.part` 文件和孤儿文件，避免异常退出后列表状态失真。

### 本地音乐

- 支持添加本地音乐目录并递归扫描。
- 支持的音频扩展名包括：MP3、FLAC、M4A、AAC、WAV、OGG、OPUS、WMA、APE、AIFF、ALAC。
- 支持读取本地音频标签、时长、码率和内嵌封面。
- 标签读取失败时不会丢弃文件，会回退到文件名和「未知歌手」。
- 支持增量扫描、重新扫描、启动时清理不存在的文件。
- 下载目录会自动作为本地音乐目录的一部分。
- 支持在线刮削本地歌曲身份，把匹配到的歌名、歌手、专辑、封面、平台 ID、hash 等同步进本地索引。
- 支持把刮削到的元数据写回本地文件标签。
- iOS 使用安全作用域目录恢复权限；Android 支持媒体读取权限和目录访问兼容处理。

### 排行榜

- 支持 QQ 音乐、酷我音乐、网易云相关榜单入口。
- 榜单页按平台展示榜单卡片，可进入榜单详情。
- 榜单歌曲支持播放、收藏和正在播放高亮。
- 支持榜单显示设置，可以隐藏 / 恢复平台或具体榜单。
- 榜单封面加载失败时使用稳定生成的占位渐变图，避免页面空白。

### 猜你喜欢

- 基于收藏和播放历史生成推荐。
- 当收藏歌曲达到一定数量后，从收藏样本中建立歌手、专辑、平台画像。
- 对候选歌曲按相似度和近期播放反馈打分，返回推荐理由。
- 自动排除已收藏歌曲，以及同名同歌手的跨平台重复歌曲。

### 听歌统计

- 自动记录播放历史。
- 支持按周、月、年查看统计。
- 展示播放次数、听歌时长、活跃天数等摘要数据。
- 支持每日播放热力图。
- 支持歌曲、歌手、专辑 Top 排行。

### 自定义音源

- 支持手动添加脚本源。
- 支持从本地文件导入脚本。
- 支持从链接导入脚本。
- 支持粘贴脚本导入。
- 支持启用 / 禁用、初始化、编辑和删除自定义源。
- 自定义源运行时包含脚本校验、安全限制和运行时 polyfill。
- 支持源能力识别，按脚本能力参与搜索、歌词、播放地址等流程。

### 云端同步

- 支持配置自建 Workers 服务地址。
- 支持云端账号注册、登录和登出。
- 支持同步收藏、普通歌单、设置和自定义音源。
- 支持本地与云端合并，歌单默认采用去重并集合并策略。
- 支持同步阶段提示、网络恢复后自动尝试同步、App 前后台生命周期同步。
- Token 使用安全存储，云端会话和服务地址分开管理。
- 同步请求有体积限制和分批处理，适配 Workers 的请求体限制。

### 设置与数据维护

- 支持系统 / 浅色 / 深色主题。
- 支持播放音质和下载音质分别设置。
- 支持默认搜索平台设置。
- 支持自动恢复播放设置。
- 支持仅 Wi‑Fi 下载设置。
- 支持导出和导入备份，覆盖歌单、搜索历史、主题、音质、下载策略、自动恢复播放、默认搜索平台和额外设置。
- 备份导入带大小、字段、歌单数量、歌曲数量和 JSON 预算校验，避免异常文件破坏本地数据。
- 支持清理缓存、查看应用日志和复制设备 ID。

### 交互与界面

- 首页提供搜索、随机播放收藏、猜你喜欢、本地音乐、下载管理、听歌统计、睡眠定时、主题切换等快捷入口。
- 底部主导航支持左右滑动切换页面。
- 列表、卡片和页面切换带轻量动画，并支持减少动态效果。
- 顶栏和页面使用渐变遮罩，滚动时减少突兀的背景切换。
- 统一使用应用内通知提示播放、下载、同步和错误状态。
- 桌面宽屏会自动限制内容宽度，移动端保持单手友好的布局。

## 内置音源

当前内置音源管理器注册了以下平台：

| 平台 ID | 名称 |
| --- | --- |
| `tx` | QQ 音乐 |
| `kw` | 酷我音乐 |
| `wy` | 网易云音乐 |

另外还支持：

- `all`：全网搜索聚合入口。
- `local`：本地音乐索引。
- `favorites`：收藏列表内搜索。
- 自定义源：由用户导入并启用的脚本源。

## 支持平台

项目当前包含 Android 与 iOS 平台工程。

| 平台 | 状态 | 相关能力 |
| --- | --- | --- |
| Android | 支持 | 后台播放通知、媒体按键、本地音频读取、前台媒体服务 |
| iOS | 支持 | 后台播放、锁屏同步、小组件入口、安全作用域目录 |

代码中还包含 Windows 便携模式支持逻辑：当 Windows 可执行文件旁存在 `portable.flag` 时，会把配置、封面缓存和下载目录放到 `portable_data` 下。但当前仓库没有 Windows 平台工程目录，如需 Windows 打包需要先补齐 Flutter Windows 平台工程。

## 权限说明

### Android

Android 工程声明了以下主要权限：

- `INTERNET`：访问搜索、歌词、播放地址和云同步服务。
- `WAKE_LOCK`：后台播放时保持播放任务稳定。
- `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_MEDIA_PLAYBACK`：后台播放媒体服务。
- `POST_NOTIFICATIONS`：Android 13+ 播放通知和媒体控制。
- `READ_MEDIA_AUDIO`：Android 13+ 读取本地音频。
- `READ_EXTERNAL_STORAGE`：Android 12 及以下读取本地音频。

### iOS

iOS 侧使用后台音频、锁屏信息、小组件深链和安全作用域目录相关能力。目录访问依赖系统文件选择器授权，授权恢复逻辑会在启动时尝试重新绑定之前选择的目录。

## 技术栈

- Flutter / Dart
- Riverpod：状态管理和依赖注入
- GoRouter：路由与 Shell 导航
- audio_service / just_audio：后台播放和音频播放
- Dio：网络请求
- shared_preferences / flutter_secure_storage：普通配置与安全 Token 存储
- file_picker / permission_handler：目录选择和权限申请
- audio_metadata_reader：本地音频元数据读取
- flutter_js：自定义源脚本运行
- home_widget / live_activities：iOS 小组件和动态能力集成

## 项目结构

```text
lib/
  app.dart                         # MaterialApp、主题、全局通知、同步宿主
  main.dart                        # 启动初始化、音频服务、下载/本地音乐/同步恢复
  router/                          # GoRouter 路由和页面转场
  core/
    audio/                         # 播放 Handler、队列、缓存、命令协调
    network/                       # HTTP、音源解析、媒体传输策略
    storage/                       # 配置存储、Token、缓存维护、便携模式
    theme/                         # 应用主题和颜色
    widgets/                       # 通用 UI 组件、弹窗、按钮、封面、通知
  features/
    search/                        # 搜索页、搜索状态、歌单详情
    player/                        # 播放服务、全屏播放器、迷你播放器、会话恢复
    playlist/                      # 歌单、收藏、重复检测、导入导出相关逻辑
    download/                      # 下载任务、下载服务、下载管理页
    local_music/                   # 本地扫描、刮削、标签写入和本地音乐设置
    lyric/                         # 歌词获取、解析和显示
    leaderboard/                   # 榜单和榜单可见性设置
    recommend/                     # 猜你喜欢推荐引擎
    stats/                         # 播放历史和听歌统计
    custom_source/                 # 自定义源管理、脚本校验和运行时
    sync/                          # 云端同步协调、状态机、游标和 outbox
    cloud/                         # Workers API 客户端和会话
    settings/                      # 设置页、备份导入导出、日志入口
```

## 本地开发

### 环境要求

项目配置要求：

- Dart SDK：`>=3.12.0 <4.0.0`
- Flutter：`>=3.44.0`

请先安装 Flutter，并确保目标平台的 Android / iOS 开发环境可用。

### 安装依赖

```bash
flutter pub get
```

### 运行应用

```bash
flutter run
```

指定设备示例：

```bash
flutter devices
flutter run -d <device-id>
```

### 常用检查

```bash
dart format lib test
flutter analyze --no-fatal-infos
flutter test --exclude-tags live
```

如果本地还没有执行 `flutter pub get`，测试和分析前请先安装依赖。

### 构建

Android：

```bash
flutter build apk --release
```

或：

```bash
flutter build appbundle --release
```

iOS：

```bash
flutter build ios --release
```

iOS 真机打包仍需要在 Xcode 中配置签名、Bundle ID、证书和描述文件。

## 云同步服务

应用侧云同步客户端面向一个自建 Workers 服务：

1. 在「设置 → 云端账号 / 歌单」里配置 Workers 服务地址。
2. 注册或登录账号。
3. 登录后应用会同步收藏、歌单、设置和自定义音源。
4. 网络恢复或 App 回到前台时，会自动尝试继续同步。

仓库当前未包含 Workers 服务端工程。如果要启用云同步，需要自行部署兼容应用接口的服务端，并在应用内填写服务地址。

## 数据与隐私

- 歌单、播放历史、下载任务、本地音乐索引等数据默认保存在应用沙盒或系统偏好存储中。
- 云同步 Token 使用安全存储保存。
- 本地音乐扫描只索引用户选择或下载目录中的音频文件。
- 备份文件为 JSON，导入前会校验结构和大小；导出后请自行妥善保存。
- 自定义源脚本来自用户导入，使用前请确认来源可信。

## 使用建议

- 如果播放失败，先尝试降低音质；应用会自动做同源音质回退和跨平台回退，但平台侧接口不可用时仍可能失败。
- 如果本地歌曲显示为文件名或「未知歌手」，可在本地音乐设置里重新扫描并执行在线刮削。
- 收藏列表批量操作前请确认当前页，当前「全选」只会选中当前页的最多 100 首。
- 下载大量歌曲时建议开启「仅 Wi‑Fi 下载」。
- 开启云同步前建议先导出一次本地备份。

## 已知边界

- 在线搜索、歌词、播放地址、排行榜和封面依赖第三方平台接口，接口变化会导致功能临时不可用。
- 某些平台或歌曲可能没有目标音质，应用会降级或回退，但不能保证每首歌都有可播地址。
- 本地音频标签读取受文件编码和封装影响，无法解析时会回退到文件名。
- 云同步需要用户自行配置兼容的 Workers 服务端。
- 当前仓库包含 Android / iOS 工程；Windows 便携模式逻辑存在，但未包含 Windows 平台工程。
